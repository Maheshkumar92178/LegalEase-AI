# LegalEase AI

LegalEase AI is an AI-powered legal document generator designed to help users create legal documents quickly and easily.

## 📌 About the Project

LegalEase AI is a web-based application that uses Artificial Intelligence to assist users in generating legal documents based on their requirements.

The project provides a simple interface where users can enter their requirements and generate structured legal document content.

## 🎯 Objectives

- To simplify legal document creation.
- To reduce the time required to prepare basic legal documents.
- To provide an easy-to-use interface.
- To use Artificial Intelligence for document generation.
- To make legal document preparation more accessible.

## ✨ Features

- AI-powered legal document generation
- Simple and user-friendly interface
- Fast document generation
- Structured legal document content
- Backend API using FastAPI
- Frontend interface
- Health-check API
- Secure environment variable configuration

## 🛠️ Technologies Used

- JavaScript
